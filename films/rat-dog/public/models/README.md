# Model assets

- `rat-character.glb` — procedural 3D prototype, 42 named geometry parts.
- `dog-character.glb` — procedural 3D prototype, 36 named geometry parts.

These are genuine GLB meshes intended as editable/blocking assets, not feature-film final sculpts. The Remotion composition uses equivalent React Three Fiber mesh hierarchies so limbs, faces and tails can be animated deterministically from the Remotion frame number.

For feature-film quality, replace these prototypes with professionally sculpted/groomed/rigged GLB assets. The `@remotion/three` scene and choreography architecture can remain.
