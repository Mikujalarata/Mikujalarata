# 3D Rat + Dog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Remotion composition with genuine procedural 3D rat and dog characters dancing on a cinematic stage.

**Architecture:** Pure choreography math lives in `src/animation.mjs` and is unit-tested with Node. React Three Fiber character components consume the pose values. `RatDogDance3D.tsx` provides `ThreeCanvas`, lighting and deterministic scene movement.

**Tech Stack:** Remotion 4, @remotion/three, React 19, React Three Fiber 9, Three.js, TypeScript.

**Spec:** `docs/superpowers/specs/2026-08-30-3d-rat-dog-design.md`

## Global Constraints
- 1920x1080, 30fps, 12 seconds.
- Use `useCurrentFrame()` rather than `useFrame()`.
- Genuine Three.js meshes and perspective lighting; no SVG stand-ins.
- Character motion must be deterministic and scrubbable.
- Do not claim Pixar-grade quality without specialist external character assets.
