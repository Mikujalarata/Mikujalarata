# 3D Rat + Dog Remotion Design

Build a genuine 3D cartoon dance composition using Remotion, @remotion/three, React Three Fiber and Three.js. The rat and dog are procedural mesh characters with hierarchical joints, expressive faces, clothing, tails and shoes. All choreography is deterministic from `useCurrentFrame()`; no `useFrame()` or CSS animation is used. The scene uses perspective depth, soft shadows, key/fill/rim lighting, a reflective stage floor and frame-driven camera-like scene movement.

Target: 12 seconds, 1920x1080, 30fps. Visual direction: premium stylized animation / high-end commercial cartoon. This is not represented as Pixar-grade without specialist sculpting, grooming and rigging assets.
